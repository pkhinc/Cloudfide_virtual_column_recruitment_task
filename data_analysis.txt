Data Analysis of csv file sales

1. Check the file structure
import pandas as pd
df = pd.read_csv("sales.csv")
df.shape
df.head()
df.columns.tolist()
df.dtypes
df.info()
df.describe(include="all")

Result: 1507 rows, 7 columns. Column names contain spaces, including a trailing space in Quantity. Numeric columns were read as text. Use snake_case names in the pipeline.

965 rows have at least one missing value.
One row is a TOTAL row, not an order line. Remove it.
Four actual order lines have missing unit prices. Check prices for the same product.
Replace missing discounts with 0 (no discount).

3. Check duplicates

df.duplicated().sum()
df[df.duplicated(keep=False)].sort_values("Order ID")
df.duplicated(subset=["Order ID"]).sum()
df[df.duplicated(subset=["Order ID"], keep=False)].sort_values("Order ID")
df.drop_duplicates().shape

Result: 5 redundant rows (10 rows involved), no additional repeated order IDs with different data.
Assume identical rows are export duplicates. Keep the first occurrence. Do not remove rows based only on Order ID.
1502 rows after removing exact duplicates.

4. Check numeric columns

for col in ["Quantity ", "Unit Price", "Discount"]:

df[df["Quantity "].str.contains(" ", na=False)]

Result: 4 order lines with spaces as thousands separators in quantity, 7 prices with decimal commas, 1 repeated header row. The raw quantity space check also finds the repeated header.
Remove spaces from quantity, replace decimal commas with dots and remove the repeated header.

quantity = pd.to_numeric(df["Quantity "].str.replace(" ", "", regex=False), errors="coerce")
df[quantity < 0]

Result: 6 rows with negative quantities. Assume these are product returns and keep them to calculate net revenue.

5. Check prices per product

temp = df.copy()
temp = temp[~temp["Order ID"].isin(["TOTAL", "Order ID"])]
temp["Unit Price"] = pd.to_numeric(temp["Unit Price"].str.replace(",", ".", regex=False), errors="coerce")
temp.groupby("Product")["Unit Price"].agg(["nunique", "min", "max"])

Result: all 8 products have one unique known price.
Fill missing prices using the known price for the same product:
Printer paper: 21.00 (2 rows)
Keyboard: 89.00 (2 rows)
Assume missing prices are the same as other observed prices for that product.

8. Summary before building the pipeline

Raw data: 1507 rows
Remove 1 TOTAL row, 1 repeated header and 5 exact duplicates.
Expected number of order lines after cleaning: 1500.
Keep all remaining order lines, including negative quantities.
Fill 959 missing discounts after removing duplicates and technical rows.
Recover 4 missing unit prices.
Calculate revenue = quantity * unit_price - discount and aggregate by region.

Counts above refer to the raw data unless stated otherwise. Some issues overlap.
